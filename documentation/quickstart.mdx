Link the SDK, build one client at launch with your portal public key, keep it for the session. That is the full default integration.

## Prerequisites

- [Rust](https://rustup.rs/) (edition 2021), or a native engine that can load the C ABI
- A **public key** for your title from the Arcane portal
- The Arcane desktop app is installed (init opens it when a ticket must be refreshed online)

## Get started

<Steps>
  <Step title="Link the SDK">
    Rust:

    ```toml Cargo.toml
    [dependencies]
    arcane-sdk = "0.7"
    ```

    Engines (Unity / Unreal / C++): build the shared library, include `include/arcane_sdk.h`, and load the [C ABI](/reference/c-abi).

    ```bash
    cargo build --release
    ```
  </Step>
  <Step title="Build the client at launch">
    Pass the public key from the portal. `init` checks ownership as part of building the client — there is no separate ownership call.

    ```rust
    use arcane_sdk::{ArcaneClient, SdkError};

    // Public key generated in the Arcane portal for this title
    const PUBLIC_KEY: &str = "pk_...";

    fn boot() -> Result<ArcaneClient, SdkError> {
        let client = ArcaneClient::init(PUBLIC_KEY)?;
        // Owned, or DRM is disabled for this title — either way, launch.
        Ok(client)
    }
    ```

    ```c
    char err[512];
    if (arcane_sdk_init("pk_...", err, sizeof(err)) != 0) {
      /* err is "code: message — hint (context…)" — see Errors */
    }
    ```
  </Step>
  <Step title="Read state from the client, not from new calls">
    The client holds the result in memory. Nothing downstream needs the public key again.

    ```rust
    client.user_id();          // Option<&str> — the signed-in Arcane account
    client.game_id();          // Option<&str> — canonical title id
    client.is_owned();         // bool
    client.ownership();        // Owned | DrmDisabled
    client.device_hash();      // this machine's fingerprint
    client.ticket_expires_at() // Option<i64>
    ```

    ```c
    char user_id[64];
    int written = arcane_sdk_user_id(user_id, sizeof(user_id));
    /* written >= 0 on success; negative values are errors — see C ABI */
    ```
  </Step>
  <Step title="Call frame() in your render loop">
    Optional, one line. `init` already tracks playtime; `frame()` is what lets Arcane sample the frame rate.

    ```rust
    loop {
        render();
        client.frame();   // an atomic load, ~30 s per 5 min an increment too
    }
    ```

    ```c
    arcane_sdk_frame();
    ```

    Nothing else is needed. Sampling happens in 30-second windows, only while the player allows it in the Arcane desktop app, and a game that never calls `frame()` simply reports no FPS. See [Session](/concepts/session).
  </Step>
</Steps>

<Check>
  You are done for the default launch path. Store the client (or rely on the C ABI singleton) and read from it.
</Check>

<Note>
  Ownership is never revalidated on its own: a session that runs for hours and wants to re-confirm it calls `refresh()` explicitly. The client does run one lightweight thread for the play session — asleep about 59 seconds out of 60 — which reports playtime and FPS samples and never blocks your game. See [Client](/concepts/client) and [Session](/concepts/session).
</Note>

## Handle failures

Every failure is an `SdkError` with a stable `code`, a player-facing `message`, a developer-facing `hint`, and a `context` naming the values involved.

```rust
match ArcaneClient::init(PUBLIC_KEY) {
    Ok(client) => start_game(client),
    Err(err) => {
        // One log line is enough to debug:
        // not_owned: You do not own this game. — Buy it on the Arcane Store
        //   or marketplace, then retry. (detail=…)
        eprintln!("{err}");

        match err.code() {
            "not_owned" => show_store_prompt(err.message()),
            "network_required" | "not_authenticated" => show_retry(err.message()),
            _ => show_generic_error(err.message()),
        }
    }
}
```

Use `err.is_retryable()` to decide whether a retry button makes sense. The full table is in [Errors](/concepts/errors).
