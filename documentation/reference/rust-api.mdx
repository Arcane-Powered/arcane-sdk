Crate name: `arcane_sdk` (package `arcane-sdk`).

The whole public surface is one type you build at launch, plus its errors. Error codes are shared with the C ABI — see [Errors](/concepts/errors) for the full debug table.

## `ArcaneClient`

```rust
impl ArcaneClient {
    pub fn init(public_key: &str) -> Result<ArcaneClient, SdkError>;
    pub fn refresh(&mut self) -> Result<OwnershipStatus, SdkError>;

    pub fn public_key(&self) -> &str;
    pub fn game_id(&self) -> Option<&str>;
    pub fn user_id(&self) -> Option<&str>;
    pub fn device_hash(&self) -> &str;
    pub fn ownership(&self) -> OwnershipStatus;
    pub fn is_owned(&self) -> bool;
    pub fn ticket_expires_at(&self) -> Option<i64>;
    pub fn checked_at(&self) -> i64;

    pub fn frame(&self);
    pub fn set_graphics(&self, resolution: &str, preset: &str);
    pub fn session(&self) -> SessionSnapshot;
    pub fn achievements(&self) -> Achievements<'_>;
    pub fn friends(&self) -> Friends<'_>;
    pub fn shutdown(self);
}
```

`ArcaneClient` is `Debug + Clone`, and `Send + Sync`. Clones share one play session — it ends when the last one is dropped, or on `shutdown` — and one achievement cache. There is no friends cache to share: `friends().list()` always asks the Arcane desktop app.

### `init`

Build the client and check ownership. Call once at launch.

```rust
use arcane_sdk::ArcaneClient;

const PUBLIC_KEY: &str = "pk_..."; // from the Arcane portal

let client = ArcaneClient::init(PUBLIC_KEY)?;
# Ok::<(), arcane_sdk::SdkError>(())
```

Validates the public key, short-circuits to `DrmDisabled` when the cached flag says DRM is off, otherwise verifies the cached ticket. On `ticket_missing` / `ticket_expired` it contacts the Arcane desktop loopback (and may open the app) to refresh, then re-verifies. See [Ownership model](/concepts/ownership).

It then opens the play session and starts the `arcane-session` thread. That never blocks init and never fails it: if the desktop app is unreachable, tracking stays `Pending` and retries every 60 seconds, without ever opening the deep link. See [Session](/concepts/session).

**Errors:** `invalid_public_key`, `ticket_missing`, `ticket_expired`, `ticket_invalid`, `device_mismatch`, `clock_rollback`, `not_owned`, `network_required`, `not_authenticated`, `arcane_unavailable`, `ambiguous_session`, `internal`. Full causes and fixes: [Errors](/concepts/errors#error-codes).

### `refresh`

Re-run the check against Arcane desktop and update the client in place. Nothing calls this for you — there is no background revalidation.

```rust
let mut client = ArcaneClient::init(PUBLIC_KEY)?;
// … hours later …
let status = client.refresh()?;
# Ok::<(), arcane_sdk::SdkError>(())
```

On failure the client keeps its previous state.

**Errors:** same as `init` minus `invalid_public_key`.

### Accessors

All read cached state — no I/O, no failure.

`game_id` and `user_id` are `Option` because an older Arcane desktop build may not report them, and because a DRM-disabled title may have no ticket file to read them from.

They are **plain copied fields**: a clone carries the values held when the clone was made, and `refresh()` updates only the client it is called on. A clone taken before a `refresh()` that discovers a `game_id` keeps `None` — and so reports `in_game: false` for every friend. The play session and the achievement cache are shared between clones; these two are not.

### `frame`

```rust
loop {
    render();
    client.frame();
}
```

Counts one rendered frame. Outside an FPS sampling window it is a single relaxed atomic load; inside one it adds a relaxed increment. No lock, no allocation, no clock read — call it every frame at any frame rate. A game that never calls it reports no FPS samples.

### `set_graphics`

```rust
client.set_graphics("2560x1440", "high");
```

Records the current display settings, attached to the FPS samples that follow. Both strings are free-form; empty strings clear them. Takes a short lock — call it at startup and when settings change, never per frame.

### `session`

```rust
let session = client.session();
println!("{} · {}s · {:?}", session.tracking, session.played_seconds, session.last_fps_avg);
```

A copy of the session state, read from memory. Never fails.

### `achievements`

```rust
client.achievements().unlock("first_blood")?;
# Ok::<(), arcane_sdk::SdkError>(())
```

Borrows an `Achievements<'_>` accessor. It holds no state, so there is nothing to keep around. See [Achievements](/concepts/achievements).

### `friends`

```rust
client.friends().list()?;
# Ok::<(), arcane_sdk::SdkError>(())
```

Borrows a `Friends<'_>` accessor, carrying only this client's `game_id` so `in_game` can be derived. See [Friends](/concepts/friends).

## `Achievements`

```rust
impl Achievements<'_> {
    pub fn list(&self) -> Result<Vec<Achievement>, SdkError>;
    pub fn unlock(&self, key: &str) -> Result<Unlock, SdkError>;
    pub fn is_unlocked(&self, key: &str) -> Option<bool>;
}
```

`list` and `unlock` are **synchronous** — one loopback round trip each, on the calling thread, around a millisecond. Call them when something happens, never per frame. `is_unlocked` only reads memory.

### `list`

Every achievement the title defines, with this player's state, and it fills the client's cache so `is_unlocked` can answer afterwards.

**Errors:** `not_owned`, `not_authenticated`, `network_required`, `arcane_unavailable`, `feature_unavailable`.

### `unlock`

Idempotent: unlocking twice succeeds and answers `already_unlocked`, so a game can call it every time its condition holds. A `queued` answer (desktop app offline) is also a success. The cache is updated either way.

```rust
let unlock = client.achievements().unlock("first_blood")?;
if unlock.queued { /* stored locally, synchronised later */ }
# Ok::<(), arcane_sdk::SdkError>(())
```

**Errors:** `invalid_argument` when the key is empty, over `MAX_ACHIEVEMENT_KEY_LEN` bytes, made only of dots, or outside `a–z 0–9 _ - .` — keys are lowercase — raised before any network call, and also when Arcane rejects the key; `unknown_achievement`; plus the codes of `list`.

### `is_unlocked`

```rust
client.achievements().is_unlocked("first_blood");   // Some(true) | Some(false) | None
```

Reads the cache `list` filled. `None` means the SDK has nothing to answer with: `list` has never succeeded, or the key was not among the achievements it returned. Never fails, no I/O.

### `shutdown`

```rust
client.shutdown();
```

Ends the play session, reporting the final playtime to the Arcane desktop app with a 2-second timeout, and consumes the client. Dropping the last clone does the same best-effort, so this is optional.

## `Friends`

```rust
impl Friends<'_> {
    pub fn list(&self) -> Result<FriendList, SdkError>;
}
```

`list` is **synchronous** — one loopback round trip on the calling thread, around a millisecond. Call it when a friends menu opens or on a timer of your own, never per frame.

The SDK caches nothing: the Arcane desktop app caches the list for 15 seconds and reports `stale` when it served that cache while offline — a success, not an error.

```rust
let list = client.friends().list()?;
for friend in &list.friends {
    println!("{} {} {}", friend.pseudo, friend.online, friend.in_game);
}
# Ok::<(), arcane_sdk::SdkError>(())
```

`in_game` is `true` when the friend is playing the same `game_id` as this client; it is `false` for every friend when the client has no `game_id` — an older desktop build, or a clone taken before the `refresh()` that discovered one (see [Accessors](#accessors)).

**Errors:** `not_authenticated`, `network_required` (including under `ARCANE_OFFLINE_ONLY`, raised before any call), `arcane_unavailable`, `feature_unavailable`.

## `SdkError`

```rust
impl SdkError {
    pub fn code(&self) -> &'static str;       // stable, e.g. "not_owned"
    pub fn error_code(&self) -> ErrorCode;    // typed, for exhaustive matching
    pub fn message(&self) -> &str;            // player-facing
    pub fn hint(&self) -> Option<&str>;       // developer-facing next step
    pub fn context(&self) -> &[(String, String)];
    pub fn is_retryable(&self) -> bool;
    pub fn to_json(&self) -> String;
}
```

Implements `Display` (all four fields on one line), `std::error::Error`, `Debug`, `Clone`, `PartialEq`.

Match on `code()` for a stable string contract, or on `error_code()` for the typed enum. `ErrorCode` is `#[non_exhaustive]` — new codes can appear in a minor release, so keep a `_` arm.

```rust
match err.code() {
    "not_owned" => show_store_prompt(err.message()),
    "network_required" | "not_authenticated" => show_retry(err.message()),
    _ => show_generic_error(err.message()),
}
```

## Types

```rust
pub enum OwnershipStatus {
    Owned,        // valid ticket for this key, account, and device
    DrmDisabled,  // DRM off for this title; no ticket required
}

pub struct SessionSnapshot {
    pub session_id: Option<String>,   // issued by the Arcane desktop app
    pub tracking: TrackingState,
    pub played_seconds: u64,          // cumulative since init, monotonic clock
    pub fps_sampling: bool,           // the player's setting, from the desktop app
    pub samples_taken: u32,
    pub last_fps_avg: Option<f32>,
}

pub enum TrackingState {
    Active,       // the desktop app acknowledged the session
    Pending,      // local session open, desktop app not reachable yet
    Disabled,     // offline-only mode, or nobody to attribute playtime to
}

pub struct Achievement {
    pub key: String,                  // what you pass to unlock
    pub title: String,
    pub description: String,
    pub icon_url: Option<String>,
    pub hidden: bool,                 // hidden until unlocked, per the portal
    pub unlocked_at: Option<i64>,     // unix timestamp, None while locked
}

pub struct Unlock {
    pub key: String,
    pub unlocked_at: i64,             // unix timestamp Arcane recorded
    pub already_unlocked: bool,       // the player already had it — still Ok
    pub queued: bool,                 // desktop app offline; synchronised later
}

pub struct FriendList {
    pub friends: Vec<Friend>,
    pub stale: bool,                  // desktop app offline; served from its cache
}

pub struct Friend {
    pub user_id: String,              // the friend's Arcane account id
    pub pseudo: String,               // their display name on Arcane
    pub online: bool,                 // signed in to Arcane right now
    pub in_game: bool,                // playing this title right now
}

#[non_exhaustive]
pub enum ErrorCode { /* one variant per code in the Errors table */ }

pub const MAX_PUBLIC_KEY_LEN: usize = 256;
pub const MAX_ACHIEVEMENT_KEY_LEN: usize = 64;
```

`OwnershipStatus` implements `Display` (`"owned"` / `"drm_disabled"`), and `TrackingState` does too (`"active"` / `"pending"` / `"disabled"`). `SessionSnapshot` is `Debug + Clone`; `Achievement`, `Unlock`, `Friend` and `FriendList` are `Debug + Clone + PartialEq`.

crate-type = ["cdylib", "rlib", "staticlib"]

## Try it

```bash
cargo run --example client_init -- pk_your_portal_key
```

Prints every client field, renders a fake loop calling `frame()`, prints the session snapshot and ends with `shutdown()` — or the full error breakdown (code, message, hint, context, JSON) on failure.
