Crate name: `arcane_sdk` (package `arcane-sdk`).

Pass your **portal public key** into APIs whose parameter is currently named `game_id`.

Most games only need `arcane_init`. Error codes are shared with the C ABI — see [Errors](/concepts/errors) for the full debug table.

## `arcane_init`

Default launch path.

```rust
pub fn arcane_init(game_id: &str) -> Result<OwnershipStatus, SdkError>;
```

Call once at launch. Checks ownership unless cached `drm_enabled` is `false` (then returns `DrmDisabled` without a ticket).

```rust
const PUBLIC_KEY: &str = "pk_..."; // from Arcane portal

match arcane_init(PUBLIC_KEY)? {
    OwnershipStatus::Owned | OwnershipStatus::DrmDisabled => { /* continue */ }
}
```

### Errors

On failure, `Err(SdkError)` with a stable `err.code()`:

| Code | Problem |
|------|---------|
| `ticket_missing` | No ticket cache, or empty ticket while DRM is on |
| `ticket_expired` | JWT past `exp` |
| `ticket_invalid` | Bad JWT / JWKS / public key mismatch / corrupt file |
| `device_mismatch` | Ticket bound to another machine |
| `clock_rollback` | System clock earlier than ticket or last-seen time |
| `internal` | Filesystem / path failure |

Full causes and fixes: [Errors → by function](/concepts/errors#arcane_init--arcane_sdk_init) · [Error codes](/concepts/errors#error-codes-debug).

## `check_ownership_offline`

Optional. Force the offline ticket path (skips init’s DRM short-circuit). Prefer `arcane_init` for normal launch.

```rust
pub fn check_ownership_offline(game_id: &str) -> Result<OwnershipStatus, SdkError>;
```

### Errors

Same codes as [`arcane_init`](#errors) — always goes through ticket verification when DRM is on for the cached file.

See [Errors → by function](/concepts/errors#check_ownership_offline--arcane_check_ownership_offline).
