Minimal C ABI for engines that cannot call Rust directly. Build as `cdylib` or `staticlib`, include [`include/arcane_sdk.h`](https://github.com/Arcane-Powered/arcane-sdk/blob/main/include/arcane_sdk.h), then init at launch with your portal public key.

The client is a **process-wide singleton** — you init once and read from getters, with no handle to carry through C# or Blueprint.

Error codes match Rust `SdkError::code()` — use [Errors](/concepts/errors) when debugging.

## Header

```c
#include "arcane_sdk.h"
```

The header ships in the crate (`include/arcane_sdk.h`) and is attached to each GitHub Release. Regenerate after FFI changes (cbindgen **0.29.4**):

```bash
cargo install cbindgen --version 0.29.4 --locked
.github/scripts/generate-header.sh
```

## Return conventions

Two conventions, by function kind. Both are in the header as named constants.

**Actions** — `arcane_sdk_init`, `arcane_sdk_refresh`, `arcane_sdk_set_graphics`, `arcane_sdk_achievement_unlock`:

| Return | Constant | Meaning |
|--------|----------|---------|
| `0` | `ARCANE_OK` | Success |
| `1` | `ARCANE_ERR_ARGUMENT` | Bad argument, or not initialised |
| `2` | `ARCANE_ERR_SDK` | `SdkError` written to `err_buf` |

**Getters** — the `char *buf` functions:

| Return | Constant | Meaning |
|--------|----------|---------|
| `>= 0` | — | Bytes written, excluding the NUL |
| `-1` | `ARCANE_ERR_NOT_INITIALIZED` | `arcane_sdk_init` has not succeeded |
| `-2` | `ARCANE_ERR_BAD_BUFFER` | Null buffer or zero length |
| `-3` | `ARCANE_ERR_BUFFER_TOO_SMALL` | Buffer left as an empty string, never truncated |
| `-4` | `ARCANE_ERR_UNAVAILABLE` | No value to report |

## Actions

### `arcane_sdk_init`

```c
int arcane_sdk_init(const char *public_key, char *err_buf, size_t err_len);
```

Checks ownership and builds the singleton. Call once at launch. `public_key` is the **portal public key** (NUL-terminated UTF-8).

On `2`, `err_buf` holds `code: message — hint (context…)`. Parse up to the first `:` for the stable code.

**Errors:** every code in the [Errors table](/concepts/errors#error-codes) except `not_initialized`.

### `arcane_sdk_refresh`

```c
int arcane_sdk_refresh(char *err_buf, size_t err_len);
```

Re-runs the check against Arcane desktop and updates the singleton. Returns `1` if `arcane_sdk_init` has not succeeded. On failure the client keeps its previous state.

### `arcane_sdk_shutdown`

```c
void arcane_sdk_shutdown(void);
```

Ends the play session — reporting the final playtime with a 2-second timeout — then drops the client. Call it when the game exits. It is also what you want on an editor play-mode reload, where the library stays loaded across runs.

### `arcane_sdk_frame`

```c
void arcane_sdk_frame(void);
```

Counts one rendered frame, for FPS sampling. Call it once per frame from the render loop: outside a sampling window it is a relaxed atomic load, inside one it adds a relaxed increment. Does nothing before `arcane_sdk_init` succeeds, and cannot fail.

### `arcane_sdk_set_graphics`

```c
int arcane_sdk_set_graphics(const char *resolution, const char *preset);
```

Records the current display settings — for example `"2560x1440"` and `"high"` — attached to the FPS samples that follow. Empty strings clear them. Returns `1` on a null / non-UTF-8 argument or before init. Takes a short lock, so never call it per frame.

### `arcane_sdk_achievement_unlock`

```c
int arcane_sdk_achievement_unlock(const char *key, char *err_buf, size_t err_len);
```

Unlocks an achievement for the signed-in player. `key` is the key from the Arcane portal (NUL-terminated UTF-8). Idempotent — call it every time the condition holds; an already-unlocked or `queued` (desktop app offline) answer returns `0`.

One synchronous loopback call, so never call it from the render loop. Returns `1` on a null / non-UTF-8 key or before init, `2` on an SDK error written to `err_buf` — `invalid_argument` for a malformed key (keys are lowercase; raised before any call), `unknown_achievement` when the title does not define it. See [Achievements](/concepts/achievements).

### `arcane_sdk_achievement_is_unlocked`

```c
int arcane_sdk_achievement_is_unlocked(const char *key);   /* 1, 0, or -4 */
```

Reads the cache the last `arcane_sdk_achievements_json` filled — memory only, no call. Returns `1` (unlocked), `0` (locked), `-1` (not initialised), `-2` (null / non-UTF-8 key), or `-4` when the list has never been loaded or did not carry that key.

## Getters

```c
int  arcane_sdk_is_initialized(void);          /* 1 or 0 */
int  arcane_sdk_ownership(void);               /* 0 owned, 1 drm disabled, -1 not init */
long long arcane_sdk_ticket_expires_at(void);  /* unix seconds, or -1 */
long long arcane_sdk_checked_at(void);         /* unix seconds, or -1 */

int  arcane_sdk_user_id(char *buf, size_t len);
int  arcane_sdk_game_id(char *buf, size_t len);
int  arcane_sdk_public_key(char *buf, size_t len);
int  arcane_sdk_device_hash(char *buf, size_t len);
int  arcane_sdk_session_json(char *buf, size_t len);
int  arcane_sdk_achievements_json(char *buf, size_t len);
int  arcane_sdk_last_error_json(char *buf, size_t len);
```

`arcane_sdk_ownership` returns `ARCANE_OWNERSHIP_OWNED` (`0`) or `ARCANE_OWNERSHIP_DRM_DISABLED` (`1`). Both mean *launch the game*.

`arcane_sdk_last_error_json` writes the last failure as JSON — `{"code","message","hint","retryable","context"}` — for engines that want to render full detail. It returns `-4` when nothing has failed since the last success.

`arcane_sdk_session_json` writes the [play session](/concepts/session) state:

```c
char json[256];
if (arcane_sdk_session_json(json, sizeof(json)) > 0) {
  /* {"session_id":"…","tracking":"active","played_seconds":1830,
      "fps_sampling":true,"samples_taken":6,"last_fps_avg":59.8} */
}
```

`tracking` is `"active"`, `"pending"` or `"disabled"`.

`arcane_sdk_achievements_json` is the C form of the Rust `list()`: it makes one synchronous loopback call, writes every [achievement](/concepts/achievements) of the title, and fills the cache `arcane_sdk_achievement_is_unlocked` reads. Call it on a loading or achievements screen, never per frame.

```c
char json[4096];
if (arcane_sdk_achievements_json(json, sizeof(json)) > 0) {
  /* {"achievements":[{"key":"first_blood","title":"…","description":"…",
      "icon_url":"…","hidden":false,"unlocked_at":1777638896}]} */
}
```

`unlocked_at` is a Unix timestamp, or `null` while locked. A `-4` here means the call failed — read `arcane_sdk_last_error_json` for the code.

Buffer sizing: user ids and device hashes fit comfortably in 64 bytes; allow 256 for the session JSON, 512 for `err_buf`, 1024 for the error JSON, and size the achievement JSON to your title (a few hundred bytes per achievement). A short buffer is never a silent truncation — you get `-3` and an empty string.

## Example

```c
#include "arcane_sdk.h"
#include <stdio.h>

int boot(void) {
  char err[512];
  int rc = arcane_sdk_init("pk_...", err, sizeof(err));

  if (rc == ARCANE_ERR_ARGUMENT) {
    return 0;                      /* null or non-UTF-8 key */
  }
  if (rc == ARCANE_ERR_SDK) {
    fprintf(stderr, "arcane: %s\n", err);   /* "not_owned: … — Buy it on …" */

    char json[1024];
    if (arcane_sdk_last_error_json(json, sizeof(json)) > 0) {
      /* structured form for your telemetry or an in-game dialog */
    }
    return 0;
  }

  char user_id[64];
  if (arcane_sdk_user_id(user_id, sizeof(user_id)) >= 0) {
    printf("signed in as %s\n", user_id);
  }

  arcane_sdk_set_graphics("2560x1440", "high");
  return 1;                        /* Owned or DrmDisabled — launch */
}

void on_boss_defeated(void) {
  char err[512];
  arcane_sdk_achievement_unlock("boss.01", err, sizeof(err));   /* idempotent */
}

void render_frame(void) {
  draw();
  arcane_sdk_frame();              /* one atomic load per frame */
}

void quit(void) {
  arcane_sdk_shutdown();           /* reports the final playtime */
}
```

## Safety notes

- Pointers must be valid for the duration of the call
- `err_buf` may be null or `err_len == 0` if you do not need the message
- Getter buffers must point to at least `len` writable bytes
- Do not free strings owned by the SDK; only your own buffers are written into
- All functions are safe to call from any thread; the singleton is behind a lock
- `arcane_sdk_frame` takes only a read lock and no allocation — it is the one function meant for the render loop
